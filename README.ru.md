# Base Toolbar Config

[English](README.md) | **Русский**

Настройте, какие кнопки видны в панели инструментов [Bases](https://help.obsidian.md/bases) в Obsidian — как для отдельных `.base` файлов, так и для баз, встроенных в заметки. Добавляйте кнопки переключения видов, скрывайте всё лишнее и держите интерфейс чистым.

## Возможности

- **Настройка панели для каждого файла** — из интерфейса плагина или прямо из YAML `.base` файла.
- **Поддержка встроенных баз** — те же правила применяются к `![[file.base]]` внутри заметок.
- **Кастомные кнопки переключения видов** — закрепите часто используемые виды на панели в виде иконок или подписей.
- **Кнопка по умолчанию** — одна кнопка «домой» для быстрого перехода к нужному виду.
- **Перетаскивание** кастомных кнопок для изменения порядка.
- **Многоязычный интерфейс** — английский, русский, китайский (в соответствии с языком Obsidian).

## Установка

### Из списка плагинов сообщества

> Пока не опубликован. Этот раздел обновится, когда плагин появится в каталоге сообщества Obsidian.

### Вручную

1. Скачайте `main.js`, `manifest.json` и `styles.css` из [последнего релиза](../../releases).
2. Создайте папку `<ваше-хранилище>/.obsidian/plugins/base-toolbar-config/`.
3. Скопируйте туда три файла.
4. Перезапустите Obsidian и включите плагин в **Настройки → Сторонние плагины**.

## Использование

### Скрытие кнопок через настройки

1. Откройте **Настройки → Base Toolbar Config**.
2. Нажмите **+ Добавить .base** и выберите `.base` файл.
3. В разделе **Интерфейс** включите тумблеры для кнопок, которые нужно скрыть:
   - Счётчик результатов (`X результатов`)
   - Поиск
   - Свойства
   - Фильтр
   - Сортировка
   - Группа
   - Представления

### Скрытие кнопок через YAML `.base` файла

Плагин также читает блок `toolbar.hide` из самого `.base` файла. Удобно, если хотите, чтобы настройки «переезжали» вместе с файлом (например, при передаче другому пользователю).

```yaml
toolbar:
  hide:
    - search
    - filter
    - sort

views:
  - type: table
    name: "Main"
```

Оба механизма работают как **объединение**: кнопка скрыта, если она указана в `toolbar.hide` **или** включён соответствующий тумблер в настройках плагина. Неизвестные токены молча игнорируются.

#### Поддерживаемые токены

| Токен          | Что скрывает                  |
| -------------- | ----------------------------- |
| `result-count` | Счётчик "X результатов"       |
| `search`       | Кнопка поиска                 |
| `properties`   | Меню свойств                  |
| `filter`       | Меню фильтра                  |
| `sort`         | Меню сортировки               |
| `group`        | Меню группировки              |
| `views`        | Меню переключения видов       |

### Встроенные базы

Те же правила `toolbar.hide` применяются к базам, встроенным в заметки:

```markdown
![[projects.base]]
```

Плагин разрешает атрибут `src` у embed'а в реальный путь `.base` файла (включая формы `folder/file.base`, `#anchor` и `|alias`) и применяет его конфигурацию к встроенной базе.

> **Обратите внимание:** базы, вставленные как inline-блок кода ```` ```base ````, **не** обрабатываются — они не привязаны к конкретному `.base` файлу, поэтому читать конфигурацию неоткуда.

### Кастомные кнопки переключения видов

Любой вид из `.base` файла можно закрепить на панели:

1. В **Настройках → Base Toolbar Config** выберите `.base` файл.
2. В разделе **Пользовательские кнопки** нажмите **+ Добавить**.
3. Выберите иконку, привяжите вид и укажите режим отображения:
   - **Иконка** — компактно, только иконка.
   - **Текст** — иконка + название вида, удобно в широких панелях.
4. Перетаскивайте строки, чтобы изменить порядок.

Также можно включить **Кнопку по умолчанию** — она одним кликом переключает на заданный вид.

### Стиль меню видов

Включите **Включить кастомный стиль меню видов** в разделе **Интерфейс**, чтобы панель аккуратно переносилась при недостатке ширины. Полезно для встроенных баз в узких колонках.

## Стилизация в темах

Все элементы интерфейса используют стандартные CSS-переменные Obsidian (`--background-modifier-hover`, `--interactive-accent`, `--text-normal` и др.), поэтому автоматически адаптируются к светлой/тёмной теме и темам сообщества.

Чтобы переопределить стили плагина, используйте классы:

- `.my-base-btns-container` — обёртка для вставленных кнопок
- `.my-base-btn` — отдельная кастомная кнопка
- `.bvs-text-mode` — применяется, когда кнопка показывает текст
- `.bth-hide-<token>` — навешивается на контейнер, когда кнопку нужно скрыть (`search`, `filter`, `sort`, `properties`, `result-count`, `group`, `views`)
- `.bvs-hide-<token>` — legacy-алиасы для обратной совместимости

## Требования

- Obsidian **1.13.0** или новее (плагин использует `getSettingDefinitions()` и `setDestructive()`, появившиеся в 1.13).

## Разработка

```bash
# Установка зависимостей
npm install

# Режим наблюдения (пересобирает main.js при сохранении)
npm run dev

# Production-сборка
npm run build

# Линтер
npm run lint
```

Собранный `main.js` нужно скопировать в `<ваше-хранилище>/.obsidian/plugins/base-toolbar-config/` вместе с `manifest.json` и `styles.css`.

### Структура проекта

```
src/
├── main.ts                 # Точка входа: настройки, логика тулбара, i18n
└── i18n/
    ├── keys.ts             # Все ключи переводов + аугментация модуля
    ├── index.ts            # Инициализация I18N и хелпер t()
    └── locales/
        ├── en.ts
        ├── ru.ts
        └── zh.ts
styles.css                  # Скрытие кнопок + стили кастомных элементов
manifest.json
```

### Как добавить новую скрываемую кнопку

1. Добавьте токен в `HIDE_TOKEN_TO_CLASS` и `ALL_HIDE_CLASSES` в `src/main.ts`.
2. Добавьте `hideXxx` в `FileConfig`, `DEFAULT_FILE_CONFIG` и `applyConfigHideClasses`.
3. Добавьте тумблер в `getSettingDefinitions()`.
4. Добавьте ключ в `src/i18n/keys.ts` и во все файлы локалей.
5. Добавьте CSS-правило с точным классом из Obsidian (проверьте кнопку в DevTools).
